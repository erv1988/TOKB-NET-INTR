# labscripts/attacker — рабочий каталог АТАКУЮЩЕГО (192.168.56.20)

Каталог есть **в образе на обеих ВМ** (образ один и тот же). Работайте в том,
который назван `alpine-attacker`.

Файлы здесь — **символические ссылки** на `/opt/tokb/...` (эталонный набор
материалов работы). То есть `/opt/labscripts/attacker/syn_scan.py` и
`/opt/tokb/syn_scan.py` — это **один и тот же файл**: править можно по любому
пути, «поправил одно, а запустил другое» не получится.

## Какой скрипт для какого этапа

| Этап работы | Скрипт | Пример запуска |
|---|---|---|
| 2. Инвентаризация поверхности атаки | `syn_scan.py` | `sudo python3 syn_scan.py 192.168.56.10 22,80,443,8080,1000-1005` |
| 2, 3, 4. Проверка доступности сервиса | `banner_grab.py` | `python3 banner_grab.py 192.168.56.10 8080` |
| 3, 4, 7. Атака SYN-флудом | `syn_flood.py` | `sudo python3 syn_flood.py 192.168.56.10 8080 --spoof --duration 30` |
| 6, 7. ARP-спуфинг («человек посередине») | `arp_spoof.py` | `sudo python3 arp_spoof.py eth0 192.168.56.10 192.168.56.1` |

Полезно рядом:

- `nmap` — то же сканирование готовой утилитой (`nmap -sS -Pn -p 1-1000 192.168.56.10`),
  нужно для сравнения «своими руками vs готовый инструмент»;
- `tcpdump` — захват трафика в файл для Wireshark (см. этап 1);
- `mc` — просмотр и правка файлов (см. ниже).

## Как посмотреть и поправить файл: mc

```bash
mc                    # файловый менеджер: две панели, F10 — выход
mc -v syn_flood.py    # просмотр файла (то же, что F3 на файле)
mc -e syn_flood.py    # правка файла (то же, что F4 на файле)
```

Клавиши в файловых панелях:

| Клавиша | Действие |
|---|---|
| **F3** | просмотр файла (View) |
| **F4** | правка файла во встроенном редакторе (Edit) |
| **F5** | копировать, **F6** — перенести/переименовать |
| **F7** | создать каталог, **F8** — удалить |
| **Tab** | переключить панель; **Ctrl-O** — спрятать панели и вернуться в консоль |
| **F10** | выход из mc |

Клавиши во встроенном редакторе (mcedit):

| Клавиша | Действие |
|---|---|
| **F2** | сохранить файл |
| **F7** | поиск, **F4** — замена по тексту |
| **F10** / **Esc** | выход (с предложением сохранить) |

Совет: `Ctrl-O` удобно нажать, чтобы прямо из mc запустить атаку, а потом
вернуться к тем же панелям. Свои доработки скриптов (по вариантам заданий)
складывайте в домашний каталог — `cp syn_flood.py ~/my_syn_flood.py` — так
эталонный файл в `/opt/tokb` останется целым.
