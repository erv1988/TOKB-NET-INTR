# labscripts/victim — рабочий каталог ЖЕРТВЫ (192.168.56.10)

Каталог есть **в образе на обеих ВМ** (образ один и тот же). Работайте в том,
который назван `alpine-victim`.

Файлы здесь — **символические ссылки** на `/opt/tokb/...` (эталонный набор
материалов работы). То есть `/opt/labscripts/victim/firewall_lab.sh` и
`/opt/tokb/firewall_lab.sh` — это **один и тот же файл**: править можно по
любому пути, «поправил одно, а запустил другое» не получится.

## Какой скрипт для какого этапа

| Этап работы | Скрипт | Пример запуска |
|---|---|---|
| 1–4. Учебный сервис на порту 8080 | `vuln_service.py` | `python3 vuln_service.py 8080` |
| 4, 6, 7. Межсетевой экран на iptables | `firewall_lab.sh` | `sudo ./firewall_lab.sh stateful` |
| 5. Проверка правил Snort без сети | `verify_ids.py` | `SNORT_CFG=/etc/snort/lab.lua python3 verify_ids.py` |
| 7. Свой мини-IDS/IPS на scapy | `mini_ids.py` | `sudo python3 mini_ids.py --iface eth0 --monitor --log-file /tmp/alerts.log` |

Режимы `firewall_lab.sh`: `show` (показать текущие правила), `stateful`,
`synvuln` (временно ОТКЛЮЧИТЬ защиту — для «до» в этапе 3), `synflood`
(ограничение скорости), `arp` (защита от ARP-спуфинга), `reset` (снять все
правила, вернуть политику ACCEPT).

Режимы `mini_ids.py`: `--monitor` (только обнаружение) и `--block` (добавляет
правило `iptables -I INPUT -s <IP> -j DROP`; по Ctrl+C правила снимаются
сами). `--iface eth0`, `--log-file <файл>`.

## Что лежит рядом (не в этом каталоге)

| Где | Что |
|---|---|
| `/etc/snort/lab.conf` | учебный конфиг Snort в читаемом 2.9-формате (текст для разбора) |
| `/etc/snort/lab.lua` | **рабочий** конфиг Snort 3 — его подставляют ключом `-c` |
| `/etc/snort/rules/lab.rules` | правила обнаружения (скан портов, SYN-флуд) |

## Как посмотреть и поправить файл: mc

```bash
mc                              # файловый менеджер: две панели, F10 — выход
sudo mc -e /etc/snort/lab.lua   # правка конфига Snort от root (то же, что F4)
sudo mc -v /etc/snort/rules/lab.rules   # просмотр правил (то же, что F3)
```

Клавиши в файловых панелях:

| Клавиша | Действие |
|---|---|
| **F3** | просмотр файла (View) |
| **F4** | правка файла во встроенном редакторе (Edit) |
| **F5** | копировать, **F6** — перенести/переименовать |
| **F7** | создать каталог, **F8** — удалить |
| **Tab** | переключить панель; **Ctrl-O** — спрятать панели и вернуться в консоль |
| **F10** | выход из mc |

Клавиши во встроенном редакторе (mcedit):

| Клавиша | Действие |
|---|---|
| **F2** | сохранить файл |
| **F7** | поиск, **F4** — замена по тексту |
| **F10** / **Esc** | выход (с предложением сохранить) |

> Файлы из `/etc/` требуют прав root — открывайте их через `sudo mc -e <файл>`
> или запускайте `sudo mc` целиком. `lab.lua` дважды пригодится в этапах 5 и 6:
> там меняют MAC шлюза в блоке `arp_spoof` (в образе стоит заглушка
> `00:11:22:33:44:55`).
